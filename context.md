Computer Vision Project Description
Course: Computer Vision
Program: BS Computer Science
Semester: VIII
Total Marks: 5
Deadline: 30th April 2026: 11:59 pm (No extension in deadline)
Group size: 3 (Max) or 1
1. Objective
The objective of this project is to provide hands-on experience in solving real-world computer vision problems using either Multi-Label Classification OR Object Detection techniques. Students will explore deep learning approaches using pre-trained CNN models and evaluate their performance.
2. Project Requirements
a. Choose ONE Task
Option 1: Multi-Label Image Classification
Option 2: Object Detection
b. Dataset
Minimum dataset size: 5000 images
Use existing dataset or create your own dataset
If dataset is smaller, apply data augmentation to reach 5000 images
c. Models
Use at least 3 different pre-trained CNN backbone models (ResNet, VGG, EfficientNet, MobileNet)
Perform comparative analysis
d. Training Requirements
Must use Dropout
Must use Early Stopping
Must use Weight Decay (L2 Regularization)
e. Analysis Requirement
Compare performance with and without Dropout, Early Stopping, and Weight Decay. Discuss improvements or negative impacts and reasons.
3. Submission Requirements
Submit a Jupyter Notebook (.ipynb) including:
1. Project Title & Description
2. Dataset Details
3. Data Preprocessing & Augmentation
4. Model Architectures (3 models)
5. Training Details
6. Results (Accuracy, Precision, Recall, F1-score / mAP, IoU)
7. Comparative Analysis
8. Conclusion
9. Implementation Code
